## 一、目标概述

### 1.1 当前问题

```
┌─────────────────────────────────────────────┐
│                                             │
│          聊天界面 (100% 宽度)               │
│              被侧边栏遮挡                    │
│                              ┌──────────────┤
│                              │  侧边栏       │ ← 悬浮覆盖
│                              │  z-index:50  │
│                              └──────────────┘
└─────────────────────────────────────────────┘
```

### 1.2 优化目标

```
┌─────────────────────────────────┬─────────────┐
│                                 │             │
│     聊天界面 (50-60%)            │   侧边栏     │
│     动态压缩，不遮挡             │   (40-50%)   │
│                                 │             │
└─────────────────────────────────┴─────────────┘
```

### 1.3 核心改动

1. **聊天容器动态宽度** - 侧边栏打开时自动压缩
2. **平滑过渡动画** - 300ms cubic-bezier 缓动
3. **响应式适配** - 移动端保持原样（全屏覆盖）
4. **拖拽调节** - 支持用户自定义宽度比例

### 任务 3.4：添加拖拽调节宽度

**文件：** `src/components/HtmlSidebar.vue`

**改动内容：**

1. **添加拖拽手柄**
```vue
<template>
  <div class="sidebar-container">
    <!-- 拖拽手柄 -->
    <div
      v-if="!isMobile"
      class="resize-handle"
      @mousedown="startResize"
    >
      <div class="handle-line"></div>
    </div>

    <!-- 现有内容 -->
    <div class="sidebar-content">...</div>
  </div>
</template>
```

2. **添加拖拽逻辑**
```typescript
const isResizing = ref(false)
const startX = ref(0)
const startWidth = ref(50)

const startResize = (e: MouseEvent) => {
  isResizing.value = true
  startX.value = e.clientX
  startWidth.value = globalStore.sidebarConfig.width || 50

  document.addEventListener('mousemove', onResize)
  document.addEventListener('mouseup', stopResize)
}

const onResize = (e: MouseEvent) => {
  if (!isResizing.value) return

  const deltaX = startX.value - e.clientX
  const windowWidth = window.innerWidth
  const deltaPercent = (deltaX / windowWidth) * 100

  let newWidth = startWidth.value + deltaPercent
  newWidth = Math.max(30, Math.min(70, newWidth))

  globalStore.updateSidebarConfig({ width: Math.round(newWidth) })
}

const stopResize = () => {
  isResizing.value = false
  document.removeEventListener('mousemove', onResize)
  document.removeEventListener('mouseup', stopResize)
}
```

3. **添加手柄样式**
```css
.resize-handle {
  position: absolute;
  left: 0;
  top: 0;
  bottom: 0;
  width: 6px;
  cursor: col-resize;
  background: transparent;
  z-index: 10;
}

.resize-handle:hover .handle-line {
  opacity: 1;
}

.handle-line {
  position: absolute;
  left: 2px;
  top: 50%;
  transform: translateY(-50%);
  width: 2px;
  height: 40px;
  background: #3b82f6;
  border-radius: 1px;
  opacity: 0;
  transition: opacity 0.2s;
}
```

**验证标准：**
- ✅ 拖拽手柄显示在侧边栏左侧
- ✅ 拖拽时宽度实时调整
- ✅ 限制在 30%-70% 范围内
- ✅ 移动端不显示手柄

```typescript
// 从 localStorage 读取
state: (): GlobalState => ({
  sidebarConfig: {
    width: Number(localStorage.getItem('sidebarWidth')) || 50,
    // ... 其他配置
  }
})

// 保存到 localStorage
updateSidebarConfig(config: Partial<SidebarConfig>) {
  this.sidebarConfig = { ...this.sidebarConfig, ...config }
  if (config.width !== undefined) {
    localStorage.setItem('sidebarWidth', String(config.width))
  }
}
```
