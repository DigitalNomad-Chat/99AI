## 已知注意事项

### 1. 样式优先级

由于使用了 Element Plus 主题覆盖，需要注意样式优先级：
- 自定义样式优先级高于 Element Plus 默认样式
- Element Plus 组件的 `style` 属性会覆盖全局样式
- 必要时使用 `:deep()` 或 `::v-deep` 穿透样式

### 2. 浏览器兼容

所有样式使用标准 CSS3 特性，兼容性良好：
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

### 3. 性能建议

- 样式文件已合并，生产环境会自动优化
- 使用 `backdrop-filter` 的组件已在关键区域限制使用
- 阴影和动画使用 CSS 硬件加速

### 4. 后续优化建议

如需进一步优化：
1. **代码分割** - 使用动态导入减少初始包大小
2. **CSS压缩** - 启用更激进的压缩配置
3. **组件按需加载** - Element Plus 按需引入组件
4. **CDN 加速** - 静态资源 CDN 托管
