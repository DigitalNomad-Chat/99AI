# 分屏布局实施总结

> **项目：** 99AI HTML 预览分屏布局
> **实施日期：** 2026年1月23日
> **状态：** ✅ 完成

---

## 一、问题回顾

### 原始问题

1. **侧边栏遮挡聊天区域** - 打开时侧边栏会滑过并遮挡聊天内容
2. **拖拽不响应** - 调整侧边栏宽度时，聊天界面不会跟随变化

### 根本原因

- **架构问题**：聊天容器在 chatBase.vue 的 flex 容器内，侧边栏使用 `teleport to="body"` + `fixed` 定位
- **层级隔离**：两者不在同一个 DOM 层级，无法协调布局
- **CSS 变量同步延迟**：拖拽时 store 更新是同步的，但 CSS 变量更新需要等待 Vue 响应式周期

---

## 二、解决方案：统一 Flex 容器

### 核心思路

将聊天容器和侧边栏纳入**同一个 flex 容器**，让 flex 布局自动处理宽度分配。

### 新架构

```
chatBase.vue
├── .split-screen-container (flex 容器)
│   ├── .chat-area (flex: 1, 自动伸缩)
│   └── HtmlSidebar (flex-basis: 动态宽度)
```

---

## 三、实施的修改

### 1. HtmlSidebar.vue 重构

**移除 Teleport**：
```vue
<!-- 修改前 -->
<teleport to="body">
  <div class="fixed ...">...</div>
</teleport>

<!-- 修改后 -->
<div class="sidebar-container desktop-mode">...</div>
```

**改用 Flex 布局**：
```javascript
const sidebarStyle = computed(() => {
  return {
    flexBasis: isVisible.value ? `${width}%` : '0%',
    minWidth: isVisible.value ? '30%' : '0',
    maxWidth: '80%',
    opacity: isVisible.value ? '1' : '0',
    transition: isAnimationEnabled.value
      ? 'flex-basis 0.3s cubic-bezier(0.4, 0, 0.2, 1), opacity 0.2s ease'
      : 'none',
  }
})
```

**桌面端/移动端分离**：
```css
.sidebar-container.desktop-mode {
  position: relative;  /* 不再 fixed */
  flex-shrink: 0;
}

.sidebar-container.mobile-mode {
  position: fixed;  /* 移动端保持覆盖 */
}
```

### 2. chatBase.vue 结构调整

**统一 Flex 容器**：
```vue
<div class="split-screen-container">
  <div class="chat-area" :class="{ 'sidebar-open': sidebarVisible }">
    <!-- 聊天内容 -->
  </div>

  <HtmlSidebar v-if="showHtmlPreviewer && previewDisplayMode === 'sidebar'" />
</div>
```

**CSS 使用 Flex**：
```css
.split-screen-container {
  display: flex;
  width: 100%;
  height: 100%;
}

.chat-area {
  flex: 1;
  min-width: 350px;
}
```

### 3. App.vue 清理

**移除全局 HtmlSidebar 引用**：
```vue
<!-- 修改前 -->
<HtmlSidebar v-if="showHtmlPreviewer && previewDisplayMode === 'sidebar'" />

<!-- 修改后 -->
<!-- 侧边栏模式在 chatBase.vue 中处理 -->
<!-- 仅保留模态框模式的 HtmlDialog -->
<HtmlDialog v-if="htmlDialog || (showHtmlPreviewer && previewDisplayMode === 'modal')" />
```

## 四、关键技术点

### 1. Flex 布局协调

- **聊天区域**：`flex: 1` → 自动占据剩余空间
- **侧边栏**：`flex-basis: 50%` → 固定占比

当侧边栏宽度变化时，聊天区域**自动**调整宽度，无需手动同步。

### 2. 动画效果

**打开/关闭动画**：
```css
transition: flex-basis 0.3s cubic-bezier(0.4, 0, 0.2, 1), opacity 0.2s ease;
```

- `flex-basis` 变化控制宽度
- `opacity` 变化控制淡入淡出
- 使用 `cubic-bezier(0.4, 0, 0.2, 1)` 创建自然缓动

**拖拽时禁用动画**：
```javascript
globalStore.updateSidebarConfig({ animation: false })
```

### 3. 拖拽调整逻辑

```javascript
const onResize = (e: MouseEvent) => {
  const deltaX = startX.value - e.clientX
  const newWidth = calculateNewWidth(deltaX)

  // 直接更新 store，触发响应式变化
  globalStore.updateSidebarConfig({ width: Math.round(newWidth) })
}
```

由于使用 flex 布局，store 更新会**自动**反映到布局中，无需手动操作 CSS。

### 4. 视觉分隔

```css
.chat-area.sidebar-open {
  border-right: 1px solid rgb(229 231 235);
}
```

在聊天区域右侧添加边框，清晰分隔两个面板。

## 八、后续优化建议

### 可选改进

1. **宽度记忆** - 将用户设置的宽度保存到 localStorage

1. **虚拟滚动** - 如果侧边栏内容很多，考虑使用虚拟滚动
2. **懒加载** - iframe 内容可以延迟加载
3. **动画优化** - 使用 `will-change` 提示浏览器优化

## 九、总结

### 实施成果

- ✅ **解决了两个核心问题**：遮挡和拖拽不响应
- ✅ **实现了真正的分屏布局**：类似 Claude/LobeChat
- ✅ **代码更简洁**：移除了复杂的 CSS 变量同步逻辑
- ✅ **性能更优**：flex 布局由浏览器原生处理

### 技术亮点

- **架构重构**：从分离的 fixed 定位改为统一的 flex 容器
- **响应式优先**：桌面端分屏，移动端覆盖
- **动画精致**：使用 cubic-bezier 创建自然缓动
- **交互流畅**：拖拽即时响应，无延迟

### 学习要点

1. **Flex 布局优于手动计算** - 让浏览器处理布局协调
2. **统一容器优于分离组件** - 消除层级隔离
3. **CSS 过渡优于 JS 动画** - 性能更好，代码更简洁
4. **响应式设计要考虑多种场景** - 桌面/移动/模态框
