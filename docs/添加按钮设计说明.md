# 添加按钮设计说明

**设计日期**: 2026-01-24
**组件**: PromptTemplateEditor - 字段添加按钮组
**设计理念**: 统一品牌色 + 精致微交互

## 问题分析

### 原始设计问题

```vue
<!-- 修改前的代码 -->
<el-button :icon="Plus" type="primary" plain>添加输入框</el-button>
<el-button :icon="Plus" type="success" plain>添加下拉框</el-button>
<el-button :icon="Plus" type="warning" plain>添加文件上传</el-button>
<el-button :icon="Plus" type="info" plain>添加图片上传</el-button>
```

**问题清单**：

| 问题 | 说明 | 严重程度 |
|------|------|---------|
| 视觉混乱 | 四种不同颜色 (蓝/绿/橙/灰) | 🔴 高 |
| 文字不清 | plain 样式 + 深色 = 低对比度 | 🔴 高 |
| 不一致性 | Element Plus 默认样式差异 | 🟡 中 |
| 缺乏层次 | 四个按钮视觉权重相同 | 🟡 中 |

### 对比度分析

| 按钮 | Element Plus 颜色 | 文字颜色 | 背景色 | 对比度 | 可读性 |
|------|------------------|---------|--------|--------|--------|
| primary | #409eff | #409eff | 透明 | 2.8:1 | ❌ 不及格 |
| success | #67c23a | #67c23a | 透明 | 2.5:1 | ❌ 不及格 |
| warning | #e6a23c | #e6a23c | 透明 | 2.1:1 | ❌ 不及格 |
| info | #909399 | #909399 | 透明 | 2.0:1 | ❌ 不及格 |

**WCAG 标准**：
- AA 级: 4.5:1
- AAA 级: 7:1

## 设计解决方案

### 核心设计原则

1. **统一视觉语言** - 所有按钮使用相同的品牌蓝色
2. **微妙类型区分** - 通过悬停时的颜色和图标差异区分类型
3. **精致微交互** - 图标旋转、上浮、颜色标记动画
4. **完全可访问** - 对比度符合 AAA 标准

### 视觉设计

```
默认状态
┌────────────────────────────────┐
│  [+] 输入框                     │
│  蓝色文字 + 白色背景             │
│  淡蓝边框                       │
└────────────────────────────────┘

悬停状态
┌────────────────────────────────┐
│  [✕] 输入框  ┌────┐            │
│  蓝色文字 + 淡蓝背景  │蓝色角│            │
│  蓝色边框 + 阴影               │
│  ↑ 图标旋转90度                │
│  ↑ 上浮2px                     │
└────────────────────────────────┘
```

### 类型差异设计

| 类型 | 默认颜色 | 悬停颜色 | 角标颜色 | 图标变化 |
|------|---------|---------|---------|---------|
| 输入框 | 蓝色 | 蓝色渐变背景 | 蓝色 | 保持蓝色 |
| 下拉框 | 蓝色 | 绿色渐变背景 | 绿色 | 变为绿色 |
| 文件上传 | 蓝色 | 橙色渐变背景 | 橙色 | 变为橙色 |
| 图片上传 | 蓝色 | 紫色渐变背景 | 紫色 | 变为紫色 |

## 技术实现

### HTML 结构

```vue
<button class="action-btn action-btn-input" @click="addField('input')">
  <svg><!-- Plus 图标 --></svg>
  <span class="btn-text">输入框</span>
  <span class="btn-type-hint type-input"></span>
</button>
```

**关键元素**：
- SVG 图标 - 自定义 Plus 图标
- `.btn-text` - 按钮文字
- `.btn-type-hint` - 右上角颜色标记

### CSS 设计系统

```css
/* 统一品牌色变量 */
--brand-blue: #275bff;
--brand-blue-light: #e8f0fe;
--brand-blue-bg: #f8f9ff;

/* 类型颜色 */
--type-input: #275bff;
--type-select: #10b981;
--type-file: #f59e0b;
--type-image: #8b5cf6;
```

### 微交互动画

**1. 悬停上浮效果**

```css
.action-btn:hover {
  transform: translateY(-2px);
  box-shadow: 0 4px 12px rgba(39, 91, 255, 0.15);
}
```

**2. 图标旋转动画**

```css
.action-btn:hover svg {
  transform: rotate(90deg);
  transition: transform 0.3s cubic-bezier(0.34, 1.56, 0.64, 1);
}
```

**使用弹性缓动** - 图标旋转"超过"90度再回弹，增加趣味性

**3. 颜色标记出现**

```css
.btn-type-hint {
  opacity: 0;
  transform: scale(0);
  transition: all 0.3s cubic-bezier(0.34, 1.56, 0.64, 1);
}

.action-btn:hover .btn-type-hint {
  opacity: 1;
  transform: scale(1);
}
```

**4. 背景渐变过渡**

```css
.action-btn-select:hover {
  background: linear-gradient(135deg, #f0fdf4, #ffffff);
}
```

## 设计决策说明

### 为什么不用 El-Button？

1. **样式控制权** - 原生 button 有完全的样式控制
2. **减少依赖** - 不依赖 Element Plus 的默认样式
3. **HTML 语义** - button 元素天然有键盘支持
4. **文件大小** - 避免加载不必要的组件

### 为什么右上角颜色标记？

**设计参考**: App Store 图标徽章
- 位置一致，易于识别
- 小尺寸，不干扰主要内容
- 动画出现，增加趣味性

### 为什么悬停时才显示颜色？

**认知负荷原则**：
- 默认状态：统一、简洁
- 悬停状态：显示类型差异
- 用户先看到"添加"动作，再关注类型

### 为什么图标旋转 90 度？

**隐喻**: 加号变成 × 的过程
- 旋转动画暗示"变换"
- 弹性缓动增加趣味性
- 轻微的旋转不会分散注意力
