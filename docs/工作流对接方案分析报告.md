### 1.1 当前架构分析

**99AI 项目当前的应用广场功能**本质上是一个基于提示词(Prompt)的简单智能体系统，类似豆包的智能体模式。通过分析代码库，我们可以总结出当前架构的核心特征：

| 组件 | 文件路径 | 核心功能 |
|------|----------|----------|
| **后端实体** | `service/src/modules/app/app.entity.ts` | 定义应用数据模型 |
| **后端服务** | `service/src/modules/app/app.service.ts` | 应用CRUD和业务逻辑 |
| **管理员后台** | `admin/src/views/app/application.vue` | 应用配置管理界面 |
| **用户前端** | `chat/src/views/chat/components/AppList/index.vue` | 应用广场展示 |
| **@应用调用** | `chat/src/views/chat/components/Footer/index.vue` | 快捷调用应用 |

### 1.2 当前"提问模板"机制

**文件位置**: `admin/src/views/app/application.vue:1154-1179`

当前系统已经实现了较为完善的"提问模板"功能：

```typescript
// 模板字段结构

  type: 'input' | 'select'     // 字段类型
```

## 二、FastGPT 工作流接口分析

### 2.1 接口规范

**文件位置**: `/Users/a1-6/办公/GitHub/99AI/docs/fastgpt接口文档`

**核心接口**: `POST /api/v1/chat/completions`

```bash
curl --location --request POST 'http://localhost:3000/api/v1/chat/completions' \
--header 'Authorization: Bearer fastgpt-xxxxxx' \
--header 'Content-Type: application/json' \
--data-raw '{
  "chatId": "my_chatId",
  "stream": false,
  "detail": false,
  "variables": {
    "uid": "asdfadsfasfd2323",
    "name": "张三"
  },
  "messages": [
    {
      "role": "user",
      "content": "导演是谁"
    }
  ]
}'
```

### 2.2 关键参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `chatId` | string | 否 | 对话上下文ID，为空时不使用上下文 |
| `stream` | boolean | 否 | 是否流式返回 |
| `detail` | boolean | 否 | 是否返回中间值 |
| **`variables`** | **object** | **否** | **工作流变量对象** |
| `messages` | array | 是 | 消息数组(兼容GPT格式) |

### 2.3 与现有接口的对比

| 特性 | 现有智能体模式 | FastGPT工作流模式 |
|------|--------------|------------------|
| 数据传递 | 组合成提示词文本 | 结构化变量对象 |
| 文件上传 | 图片Base64/URL | 需要特殊处理 |
| 上下文管理 | 本地管理 | FastGPT管理 |
| 响应格式 | 标准GPT格式 | 支持detail中间值 |

```typescript
// 调用工作流接口
async callWorkflow(appId: number, variables: any, message: string) {
  const app = await this.appEntity.findOne({ where: { id: appId } });

  if (app.appType === 1) { // FastGPT
    return await this.callFastGPTWorkflow(app, variables, message);
  } else if (app.appType === 2) { // Dify
    return await this.callDifyWorkflow(app, variables, message);
  }

  throw new HttpException('不支持的工作流类型', HttpStatus.BAD_REQUEST);
}

private async callFastGPTWorkflow(app: AppEntity, variables: any, message: string) {
  const response = await axios.post(
    `${app.workflowApiUrl}/api/v1/chat/completions`,
    {
      chatId: `99ai_${uuidv4()}`,
      stream: false,
      variables: variables,
      messages: [{ role: 'user', content: message }]
    },
    {
      headers: {
        'Authorization': `Bearer ${app.workflowApiKey}`,
        'Content-Type': 'application/json'
      }
    }
  );

  return response.data;
}
```

## 四、前端入口策略分析

### 4.1 方案对比

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **A: 统一入口** | 用户体验一致，降低学习成本 | 工作流功能可能被忽略 | ⭐⭐⭐⭐⭐ |
| **B: 分离入口** | 功能边界清晰，易于说明 | 增加复杂度，可能造成混淆 | ⭐⭐⭐ |
| **C: 标签筛选** | 兼顾统一性和发现性 | 需要额外的UI空间 | ⭐⭐⭐⭐ |

### 4.2 推荐方案：统一入口 + 智能识别

**核心设计理念**:

> 用户不应该关心是"智能体"还是"工作流"，只关心"这个应用能做什么"

**实现细节**:

1. **应用广场保持统一入口**
   - 所有应用在同一列表展示
   - 通过视觉标识区分类型(徽章、图标)

2. **@调用时智能判断**
   ```
   普通智能体 → 直接调用(或简单配置)
   工作流应用 → 强制弹出配置界面
   ```

3. **可选的分类筛选**
   - 在分类标签旁添加类型筛选器
   - "全部 / 智能体 / 工作流"

**交互流程图**:

```
用户输入 @应用名
    ↓
系统检测应用类型
    ↓
┌─────────────┬─────────────┐
│  普通智能体  │   工作流应用  │
│             │             │
│ 直接调用或  │  弹出配置界面  │
│ 简单配置    │  (必须填写变量)│
└─────────────┴─────────────┘
```

### 5.2 文件上传处理

**FastGPT 文件上传规范**:

根据接口文档，文件上传需要转换为特定格式：

```typescript
async function handleFileUpload(field: EnhancedField, file: File) {
  // 1. 上传文件到99AI服务器
  const uploadResponse = await uploadFile(file);

  // 2. 根据FastGPT要求转换格式
  const fileVariable = {
    type: 'file',
    name: file.name,
    url: uploadResponse.data,
    // FastGPT可能需要的额外字段
    size: file.size,
    mime: file.type
  };

  // 3. 存储到formData中
  formData.value[field.variableName] = fileVariable;
}
```

## 八、扩展性设计

### 8.1 支持更多工作流平台

**架构设计**:

```typescript
// 工作流适配器接口
interface WorkflowAdapter {
  name: string;
  buildRequest(app: AppEntity, variables: any, message: any): AxiosRequestConfig;
  parseResponse(response: any): WorkflowResult;
}

// FastGPT适配器
class FastGPTAdapter implements WorkflowAdapter {
  name = 'fastgpt';
  buildRequest(app, variables, message) { /* ... */ }
  parseResponse(response) { /* ... */ }
}

// Dify适配器
class DifyAdapter implements WorkflowAdapter {
  name = 'dify';
  buildRequest(app, variables, message) { /* ... */ }
  parseResponse(response) { /* ... */ }
}

// 工作流管理器
class WorkflowManager {
  private adapters: Map<string, WorkflowAdapter>;

  constructor() {
    this.adapters = new Map([
      ['fastgpt', new FastGPTAdapter()],
      ['dify', new DifyAdapter()],
    ]);
  }

  async callWorkflow(appType: number, app: AppEntity, variables: any, message: any) {
    const adapter = this.adapters.get(this.getAdapterName(appType));
    if (!adapter) throw new Error('不支持的工作流类型');

    const request = adapter.buildRequest(app, variables, message);
    const response = await axios(request);
    return adapter.parseResponse(response);
  }
}
```
