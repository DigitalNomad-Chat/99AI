**报告日期**: 2026-01-24

## 一、问题根本原因

### 1.1 核心发现

**之前的分析不完整**：我说 "models 已有保护" 是错误的！

**实际情况**：`models.service.ts` 的保护**不完整**

| 方法 | 行号 | 保护状态 | 代码 |
|------|------|----------|------|
| `setModel` (更新分支) | 206-286 | ✅ 有保护 | `updateData.modelName = updateData.modelName \|\| curModel.modelName \|\| '默认模型'` |
| `setModel` (新建分支-单条) | 292 | ❌ **无保护** | `await this.modelsEntity.save(params)` ← 直接保存！ |
| `setModel` (新建分支-批量) | 309 | ❌ **无保护** | `await this.modelsEntity.save(data)` ← 直接保存！ |

**这就是为什么数据还是会被置空！**

---

### 1.2 问题代码

#### 问题代码1：第292行

```typescript
if (Number(keyType !== 1)) {
  const res = await this.modelsEntity.save(params);  // ← params 中字段可能是 undefined
  // ...
}
```

**风险**：如果 `params.modelName` 是 `undefined`，数据库会保存为 `NULL`。

---

#### 问题代码2：第309行

```typescript
const data = key.map(k => {
  try {
    const data = JSON.parse(JSON.stringify(params));
    data.key = k;
    // 只处理了 timeout 的 NaN 问题
    if (isNaN(data.timeout)) {
      data.timeout = null;
    }
    return data;  // ← 其他字段（如 modelName）可能是 undefined
  } catch (error) {
    console.log('parse error: ', error);
  }
});
const res = await this.modelsEntity.save(data);  // ← 直接保存，没有保护！
```

**风险**：同样的，如果 `data.modelName` 是 `undefined`，会保存为 `NULL`。

---

### 1.3 chatLog 的问题

**chatLog.service.ts:37-40**

```typescript
async saveChatLog(logInfo): Promise<any> {
  const savedLog = await this.chatLogEntity.save(logInfo);  // ← 直接保存，没有任何保护！
```

**风险**：如果 `logInfo.modelName` 是 `undefined`，会保存为 `NULL`。

## 二、完整解决方案

### 2.1 方案分类

根据之前的讨论，我们有以下方案：

| 方案 | 类型 | 状态 | 说明 |
|------|------|------|------|
| **方案一** | 临时方案 | ✅ 已实施 | 前端草稿自动保存（localStorage） |
| **方案二** | 中期方案 | ❌ 未实施 | 状态持久化中间件（usePersistedState） |
| **方案三** | 长期方案 | ❌ 未实施 | 代码结构优化（分离业务逻辑） |
| **方案四** | 辅助方案 | ❌ 未实施 | Vite 配置优化 |
| **方案五** | 安全网 | ❌ 未实施 | beforeUnload 保护 |

**但是**：这些方案主要解决的是**前端 HMR 导致的数据丢失**。

而现在的问题是**后端数据保护不完整**！

### 2.2 核心修复方案（必须执行）

#### 修复1: models.service.ts 的 save 方法

**文件**: `service/src/modules/models/models.service.ts`

**位置**: 第292行

**修改前**：
```typescript
if (Number(keyType !== 1)) {
  const res = await this.modelsEntity.save(params);
  await this.initCalcKey();
  return res;
}
```

**修改后**：
```typescript
if (Number(keyType !== 1)) {
  // 添加字段保护，确保关键字段不为空
  const saveData = {
    ...params,
    modelName: params.modelName || params.model || '默认模型',
    model: params.model || 'gpt-3.5-turbo',
    keyType: params.keyType !== undefined ? params.keyType : 0,
    status: params.status !== undefined ? params.status : 1,
  };
  const res = await this.modelsEntity.save(saveData);
  await this.initCalcKey();
  return res;
}
```

---

**位置**: 第309行

**修改前**：
```typescript
const data = key.map(k => {
  try {
    const data = JSON.parse(JSON.stringify(params));
    data.key = k;
    if (isNaN(data.timeout)) {
      data.timeout = null;
    }
    return data;
  } catch (error) {
    console.log('parse error: ', error);
  }
});
const res = await this.modelsEntity.save(data);
```

**修改后**：
```typescript
const data = key.map(k => {
  try {
    const data = JSON.parse(JSON.stringify(params));
    data.key = k;
    // 添加字段保护
    data.modelName = data.modelName || data.model || '默认模型';
    data.model = data.model || 'gpt-3.5-turbo';
    data.keyType = data.keyType !== undefined ? data.keyType : 0;
    data.status = data.status !== undefined ? data.status : 1;
    // NaN 处理
    if (isNaN(data.timeout)) {
      data.timeout = null;
    }
    return data;
  } catch (error) {
    console.log('parse error: ', error);
  }
});
const res = await this.modelsEntity.save(data);
```
