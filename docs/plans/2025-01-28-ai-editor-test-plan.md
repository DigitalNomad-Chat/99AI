#### 测试前置条件
- ✅ 后端服务已启动 (http://localhost:9520)
- ✅ 数据库已连接
- ✅ 已获取有效的JWT Token

#### TC-API-01: AI编辑功能 - 改写
**测试步骤**:
1. 登录系统，获取JWT Token
2. 使用Postman/curl发送请求:
   ```bash
   curl -X POST http://localhost:9520/api/ai/editor/edit \
     -H "Content-Type: application/json" \
     -H "Authorization: Bearer YOUR_TOKEN" \
     -d '{
       "content": "这是一段测试文字。",
       "command": "rewrite"
     }'
   ```

**预期结果**:
- ✅ HTTP状态码: 200
- ✅ 响应格式: `{"success": true, "data": {"result": "改写后的文字..."}}`
- ✅ 返回内容为中文改写版本

## 八、测试建议

### 8.1 测试顺序建议
1. **先API后UI**: 先验证后端API，再测试前端
2. **先功能后集成**: 先测单个功能，再测端到端
3. **先正常后异常**: 先测正常流程，再测异常情况

### 8.2 测试工具推荐
- **API测试**: Postman / curl / HTTPie
- **浏览器测试**: Chrome DevTools
- **网络模拟**: Chrome Network Throttling
- **性能分析**: Lighthouse

### 8.3 注意事项
1. 每个测试用例执行前确认环境正常
2. 遇到问题记录详细的复现步骤
3. 截图保存关键的失败场景
4. 测试数据使用真实场景的数据
